# Типы

## Статические, 100%

Типы статические, 100%. Базовые типы: все типы.

## Модификаторы типов

`int:id` — модификатор, не отдельный тип данных. Создаётся значением:

```text
let user_id: int:id = 42
```

Теперь 42 — это `int:id`. 42 не перестаёт быть int — все int-операции работают. Но это `int:id`.

Функция запрашивает модифицированный тип:

```text
fn get_user(int:id user_id) -> User { ... }
```

Передать можно только `int:id`. Обычный int не подойдёт — модификатора нет.

### Два варианта

| Форма | Смысл | Где используется |
|---|---|---|
| `int:id` | контракт типа: «передаются данные типа `int:id`». Кто даёт — не важно, важно, что за тип | можно везде |
| `int:=id` | источник данных: «данные даёт переменная `id`». Имя важно | только при приёме данных (параметры функций и т.п.) |

```text
fn print(int:=data) { ... }
```

`int:=id` используется только там, где данные принимаются: внутри данные доступны по имени `id`. Имя важно — это источник.

Зачем: не всегда можно заранее подготовить типы данных. `int:=id` позволяет написать, откуда придут данные конкретного типа — безопасно и без сложностей в логике. Один раз написал, что нужно тут, — и ошибок не будет.

## Именованные алиасы не нужны

Метка видна прямо на типе, ничего искать не надо.

## Единицы измерения

Единицы измерения — просто модификатор: `int:meters`. Никакой специальной арифметики единиц нет (метры², метры/секунды не вычисляются). Объявил `int:meters` — и передавай, куда нужно. Контракт — модификатор.

## Диапазоны — не в типы

Проверка диапазона — тупое сравнение, легко пишется явно:

```text
if x > 100 { ... }
```

Модификатор типа скрывал бы действие и делал его менее понятным, к тому же допускал бы выполнение действия разными способами. Если нужно — явная возможность писать о диапазоне (переменная, сигнатура функции), а не модификатор типа.

## Принцип

> В типы идёт только то, что нельзя проверить обычным кодом.

`int:id` и `int:=id` — семантические свойства, обычным кодом не проверяются → обязательны. Диапазоны — проверяются обычным кодом (`if x > 100`) → не в типы.
