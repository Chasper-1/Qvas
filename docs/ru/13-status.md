Что закрыто: всё. Концепция завершена, базовый синтаксис решён, параллелизм решён, экосистема решена, сообщения об ошибках решены, области видимости решены.

## Что решено по блокам

- **Типы** — статические, 100%. Базовые типы: все типы.
- **Структуры** — способ собрать несколько разных значений в одно, обращение по имени поля.
- **Списки и массивы** — создаются и индексируются как везде.
- **`mut` + операторы** — `mut` и move не смешиваются: `mut` меняет значение, move уносит данные. Либо одно, либо другое.
- **Инвалидация вложенных ссылок** — инвалидация целого объекта покрывает это: любая мутация объекта убивает все ссылки, производные от него, включая ссылки на поля.
- **Ссылки не пробрасываются** — функция, принимающая ссылку, — конечный читатель: читает напрямую, не передаёт ссылку дальше. Глубже — через `databox`.
- **Параллелизм** — `parallel { ... }` — блок, компилятор строит граф зависимостей и планирует сам.
- **Внешние операции** — файлы, API, системные вызовы — это просто вызовы внешних функций. Компилятору нужна их сигнатура — как везде.
- **Обработка ошибок** — модель как в Rust (`-> T or E`, проброс `?`, обработка `switch`), содержимое — любой тип, ленивый режим — автогенерация номера ошибки, подробный — пишешь сам.
- **Модули и импорты** — модуль — файл. `use std`, `link file = "file.lang"`, вызов `std.print()` / `file.sum()`, ссылка на ссылку `file::match.sum()`. Цепочки разрешены, циклы — ошибка компиляции. Передача явная. Две гарантии: видишь отдающую и принимающую сторону.
- **Функции как значения** — как везде: можно передать функцию в функцию.
- **Два вида функций** — `fn` отдаёт ответ (обязан быть потреблён: использован или в мусорку), `fn.nothing`/`fn.nil` отдаёт ответ НИЧЕГО (вызов как оператор).
- **Экосистема** — конфиг-формат, компилятор (Cranelift), шаблоны = дженерики, алиасы заменены модификаторами типов. Профилирование: встроенное, механизм зависит от возможностей Cranelift.
- **Сообщения об ошибках компилятора** — мёртвая ссылка объясняется так: «вот эта ссылка, которую ты вот тут передаёшь, вот тут её вот так убили — то есть при передаче её уже не существует». Формат: место использования ссылки → место и способ убийства (`mut`, move, смерть слота) → вывод.

## Синтаксический сахар

**Брать** (дёшево, ничего не скрывает): интерполяция строк, диапазоны + `for..in`, `while`, if-выражение, методы (`mut vec.push(x)`), вывод типов, `defer`, `?`, слайсы (`a[1:3]`), кортежи / несколько возвращаемых значений, switch, модификаторы типов (`int:id`), сокращённая запись структур (`{имя, возраст}`), неявный возврат последнего выражения, `break`/`continue`, `else if`, `+=`, comptime.

**Не брать** (не обязательно): перегрузка операторов, исключения, pattern matching (Rust-style), null-операторы, аргументы по умолчанию / именованные, макросы, интерфейсы/трейты, async/await, корутины/генераторы, рефлексия, GC/RAII, enum с данными (sum types), цепочные сравнения, метки циклов.

Принцип: не резать функционал. То, что не строим в v1, проектируем так, чтобы можно было добавить потом без поломки.

## Прочее

- Шаблоны = дженерики; шаблоны всегда раскрываются/инлайнятся.
- Enum в конфиге — одинарные обратные кавычки `` `...` ``.
- Формат конфига: строки `""`, числа `''`, массивы `{}`, таблицы `[]`, enum `` `...` ``.
