# Обработка ошибок

## Подход

Ошибка — это фича, а не баг. Ошибку разбирают там, где она возникла: на вызове. Проброса нет.

## Ошибка — значение

Ошибка — обычное значение. Что именно — решает программист:

```text
enum FileError {
    NotFound,
    PermissionDenied,
}
```

## Вычисление может вернуть «значение или ошибку»

```text
fn read_file(link path: str) -> Data or FileError {
    ...
}
```

`T or E` — ответ вычисления. Вызывающий обязан сразу разобрать результат на месте вызова, через `switch` или `match`.

## Действие отдаёт чек

`sub` работает с миром и отдаёт чек — сведения о том, что записалось, куда, сколько:

```text
sub write_file(link path: str, link data: Data) -> usize or FileError
```

Чек — не значение для вычислений, а информация. Нужен — свяжи или разбери. Не нужен — не бери: данные уже размещены, в этом и была работа.

## Ошибку разбирают на месте

```text
sub show(link path: str) {
    let result = read_file(path)
    switch result {
        FileError::NotFound => ignore!(print("файл не найден")),
        FileError::PermissionDenied => ignore!(print("нет доступа")),
        else => ignore!(print(result)),
    }
}
```

`fn` вернул `T or E` — разбирает вызывающий, сразу на вызове. `sub` вызывает только `sub`, значит ошибку разбирает вызывающая `sub` там же.

Ошибки, которую нельзя разобрать на месте, нет.

## Проброса нет

Оператора `?` в языке нет. Он выносит ошибку из места, где она возникла, — язык так не делает.

## `ignore!` — явно не брать чек

```text
ignore!(print("x"))
```

Видно в коде, что чек не используется. Голый `print("x")` — то же самое, вызов как оператор.

## Ленивый и подробный режимы

**Ленивый режим:** компилятор сам генерирует номер ошибки из места (файл, строка, вычисление или действие), номер ищешь в доках.

**Подробный режим:** сам пишешь, что положить в ошибку.

## `defer` — отложенное выполнение

`defer` — отложенное выполнение (закрытие ресурсов и т.п.):

```text
sub work() {
    let f = open(path)
    defer ignore!(f.close())
    ...
}
```

Вызов действия откладывается до выхода из блока. Если у действия есть чек, его берут или не берут там же.
