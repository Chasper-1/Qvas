# Модули

## Модуль — файл

Модуль — это файл. Импорт модуля — `use std` — вверху файла пишешь, что получаешь (как в Rust):

```text
use std
```

Подключение файла: `link file = "file.lang"` — работаешь как с библиотекой:

```text
link file = "file.lang"
```

По принятому порядку `use` и `link file` живут в своих зонах вверху файла, отделённые `---`: сначала зона `use`, затем зона `link file`, затем код. Это соглашение, не правило: компилятор его не требует, но так `link` не путается с ссылкой на данные.

## Вызов

Вызов вычисления и действия одинаковый — имя + точка + имя вызываемого:

```text
std.print()
file.sum()
```

## Прокси файла

```text
file::match.sum()
```

`::` — переход в файл, который подключён в этом файле, `.` — вызов.

Цепочки разрешены, циклы (`a ↔ b`) — ошибка компиляции.

## Передача явная

В месте вызова видно, куда передаёшь. Две гарантии: видишь отдающую сторону и принимающую.

## Области видимости

- Глобальная область — на весь файл. Глобальные просто видны по имени в своей области.
- Локальная область — тело создаёт свою область видимости (например, вычисление или действие). За пределами тела то, что написано внутри, не может быть использовано ни в каком виде.

Между файлами общее передаётся через вычисления и действия: файл делает что нужно и передаёт результат в другой файл (`file.calc()`). Общих глобалов на проект нет.
