# Модули

## Модуль — файл

Модуль — это файл. Импорт модуля — `use std` — вверху файла пишешь, что получаешь (как в Rust):

```text
use std
```

Подключение файла: `link file = "file.lang"` — работаешь как с библиотекой:

```text
link file = "file.lang"
```

## Вызов

Вызов одинаковый — имя + точка + функция:

```text
std.print()
file.sum()
```

## Ссылка на ссылку

```text
file::match.sum()
```

`::` — переход в ссылку внутри подключённого файла, `.` — вызов функции.

Цепочки разрешены, циклы (`a ↔ b`) — ошибка компиляции.

## Передача явная

В месте вызова видно, куда передаёшь. Две гарантии: видишь отдающую сторону и принимающую — ошибиться невозможно. Не определился, куда отдать — значит, не надо и передавать.

## Области видимости

- Глобальная область — на весь файл. Глобальные просто видны по имени в своей области.
- Локальная область — тело создаёт свою область видимости (например, функция). За пределами функции то, что написано внутри, не может быть использовано ни в каком виде. Где кончилась функция — там кончились возможности использования всего, что было написано ранее.

Между файлами общее передаётся через функции: файл делает что нужно и передаёт результат в другой файл (`file.func()`). Общих глобалов на проект нет.
