# Функции

## Объявление

```text
fn name(params) -> type { ... }
```

`fn` сам создаёт функцию — без `let`. Параметры с типами:

```text
fn sum(a: int, b: int) -> int {
    a + b
}
```

## Контракт функции

Параметры объявляют, читают они или потребляют. Видно в сигнатуре:

- читающий параметр — `link` (ссылка);
- потребляющий параметр — `databox` (компилятор решает копия или move по числу использований у вызывающего).

```text
fn read(link data: Data) { ... }        # чтение
fn consume(databox data: Data) { ... }  # потребление
```

## Копия от переменной с данными, не через ссылку

Копия данных берётся от переменной с данными:

```text
let c = a
```

а не через ссылку. Ссылка читает.

## Возврат — это передача данных назад

```text
fn make() -> Data {
    let d = ...
    d
}
```

Возврат — это передача данных назад, отдельный механизм не нужен.

## Мутация данных в функции

Данные пришли (потребление), поменялись через `mut`, вернулись (return = передача):

```text
fn process(databox data: Data) -> Data {
    mut data.field = new_value
    data
}
```

Отдельный механизм не нужен.

## `mut` и move не смешиваются

`mut` меняет значение, move уносит данные. Либо одно, либо другое.

## Функции как значения

Функцию можно передать в функцию — как везде:

```text
fn apply(link f: Fn, databox value: int) -> int {
    f(value)
}

let result = apply(my_func, 42)
```
