# my-lang

Низкоуровневый компилируемый язык без GC:

- простой примерно как Go;
- безопасный по памяти не хуже Rust;
- явный как Zig.

Ключевая формула: **максимум анализа во время компиляции, минимум обязательной работы во время выполнения.**

## Ключевая идея

**Нет состояния по умолчанию: чтение или использование.**

Каждое взаимодействие с данными — либо чтение (через ссылку), либо использование (через databox). Что именно — определяет контракт операции. Чтение — не потребление: читать можно сколько угодно раз.

Модель изменения состояния: не «я разрешаю изменять это», а «я изменяю это прямо сейчас» (`mut` — событие, а не разрешение).

Память автоматическая и детерминированная: без GC и подсчёта ссылок, компилятор сам решает стек/куча и освобождает в точке последнего использования. Компилятор проверяет ссылки на этапе компиляции.

## Пример

```text
let x = 10                # копия: независимое значение
link view = x             # ссылка: чтение, умирает при mut x

fn sum(a: int, b: int) -> int {
    a + b
}

let result = sum(databox(x), databox(y))   # использование: компилятор решает копия или move

parallel {
    let data = load_data()
    let ratio = compute_ratio()
    let report = build_report(data, ratio)
}
```
